# P8 — Отчёты и выгрузки

## Роль
Senior backend. Проект invotaxi-backend (P0–P7 готовы). Отчётный модуль
для диспетчеров: Excel-шаблоны и статистика. Генерация — только в ARQ
worker (openpyxl, файлы могут собираться секунды), выдача — по ссылке.

## Скоуп
1. Механика: `POST /api/v1/reports {type, params}` (dispatcher) → 202
   {report_id}; worker собирает файл в `/data/reports/{id}.xlsx`;
   `GET /reports/{id}` → статус; `GET /reports/{id}/download` →
   FileResponse. Ретенция 30 дней (cron-очистка).
2. Тип `dispatcher_sheet` (главный, формат текущего рабочего шаблона):
   по каждому водителю опубликованного плана — зелёная строка-шапка
   (имя, телефон, машина, госномер), под ней жёлтые строки заказов:
   ФИО клиента, телефон, **заявленное** время (не расчётное!), откуда,
   куда, пометка сопровождения/близнецов; сортировка по заявленному
   времени; после всех — блок «Исключения» (exception-заказы с
   причиной); лист «Методология» с параметрами расчёта (config,
   версия движка, job_id). Стили: заливка, границы, автоширина.
3. Тип `day_summary`: по плану — водителей активно, заказов размещено /
   исключений, заполненность (заказов на водителя min/avg/max), обеды
   (полные/короткие), аномалии координат по водителям.
4. Тип `unassigned_heatmap`: за период — количество exception-заказов
   по получасовым слотам × районам (данные для решения «нужна ещё
   машина на 12:00–12:30» — правило из практики). Формат: xlsx-таблица
   слоты×районы + JSON-эндпойнт `GET /api/v1/stats/unassigned?from=&to=`
   с теми же данными для будущего графика в панели.
5. `GET /api/v1/stats/anomalies?from=&to=` — счётчики GPS-аномалий по
   водителям (из P4): у кого стабильно кривые координаты — тем чинить
   трекер.

## Definition of Done
- [ ] полный цикл: publish плана (фикстура из P6) → заказ отчёта →
      скачанный xlsx открывается openpyxl и содержит ожидаемые строки
      (интеграционный тест разбирает файл обратно)
- [ ] в dispatcher_sheet ТОЛЬКО заявленное время клиента (тест: кладём
      расчётное ≠ заявленное, в файле — заявленное)
- [ ] близнецы в шаблоне помечены и идут подряд (тест)
- [ ] запрос отчёта по несуществующему/чужому id → 404 (тест)
- [ ] cron-очистка удаляет файлы старше 30 дней (тест)
- [ ] unassigned_heatmap корректно агрегирует по слотам (юнит-тест на
      агрегацию с фиксированными данными)
