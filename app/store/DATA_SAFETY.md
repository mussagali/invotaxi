# Декларация данных для магазинов

Перед отправкой сверить с фактически включёнными SDK и production-инфраструктурой.

| Тип | Собирается | Связан с пользователем | Цель | Обязательность |
|---|---:|---:|---|---|
| Телефон | да | да | аккаунт, вход, поддержка | обязательно |
| User ID | да | да | аккаунт, безопасность | обязательно |
| Точная геопозиция | для водителя | да | live-карта и выполнение поездки | для водителя |
| Адреса/координаты поездки | да | да | оформление и выполнение заказа | обязательно для заказа |
| Имя и сведения автомобиля | да | да | профиль и выполнение поездки | зависит от роли |
| История заказов | да | да | функциональность, поддержка, отчётность | обязательно |
| IP и технические журналы | да | может быть связан | безопасность и диагностика | автоматически |

- Реклама и tracking: нет.
- Продажа данных: нет.
- Передача сервис-провайдерам: хостинг/БД/уведомления и Yandex Maps в объёме, необходимом для услуги.
- Encryption in transit: отмечать «да» только после запуска всех production URL через HTTPS/WSS.
- Удаление: in-app `Профиль → Удалить аккаунт`, web `/account-deletion`, API `DELETE /api/v1/auth/me`.
- Apple App Privacy: Phone Number, Precise Location, User ID; linked; App Functionality; not tracking.
